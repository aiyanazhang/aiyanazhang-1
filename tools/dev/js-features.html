JavaScript 主要特性

1. 变量与作用域

let、const 提供块级作用域，var 提供函数作用域

let x = 10; const PI = 3.14; var y = 20;

2. 箭头函数

简洁的函数语法，自动绑定 this

const add = (a, b) => a + b; const square = x => x * x;

3. 解构赋值

从数组或对象中提取值并赋给变量

const [a, b] = [1, 2]; const {name, age} = person;

4. 模板字符串

使用反引号创建可嵌入表达式的字符串

const name = 'World'; const msg = `Hello, ${name}!`;

5. Promise 与异步

处理异步操作的现代方式

const promise = new Promise((resolve) => { setTimeout(() => resolve('完成'), 1000); });

6. 数组方法

map、filter、reduce 等强大的数组操作

const nums = [1, 2, 3, 4]; const doubled = nums.map(x => x * 2);

7. 展开运算符

展开数组或对象的元素

const arr1 = [1, 2, 3]; const arr2 = [...arr1, 4, 5];

8. 类与继承

ES6 引入的面向对象编程语法

class Animal { constructor(name) { this.name = name; } }

9. 模块化

import/export 实现代码模块化

export const myFunc = () => {}; import { myFunc } from './module';

10. 可选链与空值合并

安全地访问嵌套属性

const value = obj?.prop?.nested; const result = value ?? 'default';

11. Set 与 Map

新的数据结构，提供唯一值集合和键值对映射

const set = new Set([1, 2, 3]); const map = new Map([['key', 'value']]);

12. Async/Await

更优雅地处理异步代码

async function fetchData() { const data = await fetch(url); return data; }
