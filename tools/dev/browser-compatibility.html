JavaScript APIs

Clipboard API
Chrome
// Modern Clipboard API
navigator.clipboard.writeText('text')
  .then(() => console.log('Copied'));

navigator.clipboard.readText()
  .then(text => console.log(text));
v63+
Firefox
// Requires user permission
navigator.clipboard.writeText('text')
  .then(() => console.log('Copied'));

// readText requires explicit permission
navigator.permissions.query({
  name: "clipboard-read"
});
v63+ (Permissions)
Edge
// Same as Chrome (Chromium)
navigator.clipboard.writeText('text')
  .then(() => console.log('Copied'));

// Full support in Chromium Edge
navigator.clipboard.readText();
v79+

Detection & Feature Support

Browser Detection
Chrome
// User agent detection
const isChrome = /Chrome/.test(
  navigator.userAgent
) && /Google Inc/.test(
  navigator.vendor
);

// Feature detection (better)
if ('serviceWorker' in navigator) {
  // Chrome supports service workers
}
Firefox
// User agent detection
const isFirefox = /Firefox/.test(
  navigator.userAgent
);

// Feature detection (better)
if ('serviceWorker' in navigator) {
  // Firefox supports service workers
}
Edge
// User agent detection
const isEdge = /Edg/.test(
  navigator.userAgent
);

// Feature detection (better)
if ('serviceWorker' in navigator) {
  // Edge supports service workers
}
Best Practice: Always prefer feature detection over user agent sniffing. Use libraries like Modernizr for comprehensive feature detection.
