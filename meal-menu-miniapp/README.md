# 微信小程序随机菜单生成器 - 前端

## 项目简介

这是一个微信小程序，用于随机生成每顿饭的菜单（三菜一汤）。支持预设菜品库、自定义添加菜品和收藏功能。

## 功能特性

- 🎲 随机生成三菜一汤菜单
- 🍽️ 查看和管理菜品库（预设 + 自定义）
- ➕ 添加自定义菜品和汤品
- ⭐ 收藏喜欢的菜单
- 📋 查看和管理收藏的菜单

## 页面说明

### 1. 首页（随机生成）
- 点击"换一批"按钮随机生成三菜一汤
- 显示生成的菜单详情
- 点击"收藏这份菜单"保存喜欢的菜单

### 2. 菜品管理
- 查看所有菜品和汤品
- 区分预设菜品和自定义菜品
- 点击"添加自定义菜品"按钮添加新菜品
- 支持添加菜品或汤品两种分类

### 3. 我的收藏
- 查看所有收藏的菜单
- 显示收藏时间
- 点击"删除"按钮移除收藏

## 配置步骤

### 1. 安装微信开发者工具

下载并安装微信开发者工具：
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 2. 导入项目

1. 打开微信开发者工具
2. 选择"小程序"
3. 点击"导入项目"
4. 选择 `meal-menu-miniapp` 文件夹
5. 填写项目名称和 AppID（测试可以选择"测试号"）

### 3. 配置后端 API 地址

编辑 `app.js` 文件，修改 `apiBaseUrl`：

```javascript
App({
  globalData: {
    apiBaseUrl: 'http://your-server-ip:5000/api'  // 修改为你的后端地址
  }
})
```

**开发环境配置：**
- 如果在本地开发，使用 `http://localhost:5000/api`
- 如果使用真机调试，需要使用局域网 IP，如 `http://192.168.1.100:5000/api`

**重要：** 开发阶段需要在微信开发者工具中关闭域名校验：
1. 点击右上角"详情"
2. 选择"本地设置"
3. 勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"

### 4. 配置 AppID（可选）

编辑 `project.config.json` 文件，将 `appid` 字段修改为你的小程序 AppID：

```json
{
  "appid": "your-app-id"
}
```

如果只是测试，可以使用测试号，不需要修改此配置。

## 运行步骤

### 1. 启动后端服务

确保后端服务已启动：

```bash
cd meal-menu-backend
python app.py
```

### 2. 启动小程序

在微信开发者工具中点击"编译"按钮即可预览小程序。

### 3. 真机调试

1. 点击工具栏的"预览"按钮
2. 用微信扫描二维码
3. 在手机上查看小程序

**注意：** 真机调试时，需要确保手机和电脑在同一局域网内，并且后端 API 地址使用局域网 IP。

## 自定义配置

### 修改主题颜色

编辑 `app.json` 中的 `window` 配置：

```json
"window": {
  "navigationBarBackgroundColor": "#4CAF50",  // 导航栏背景色
  "navigationBarTextStyle": "white"           // 导航栏文字颜色
}
```

修改 `app.wxss` 或各页面的 `.wxss` 文件来调整页面样式。

### 添加 TabBar 图标

TabBar 图标需要放在 `images/` 目录下。你需要准备以下图标：
- `home.png` / `home-active.png` - 首页图标
- `dish.png` / `dish-active.png` - 菜品管理图标
- `star.png` / `star-active.png` - 收藏图标

图标建议尺寸：81px × 81px

## 常见问题

### Q: 小程序无法连接后端 API？

**A:** 检查以下几点：
1. 后端服务是否正常启动
2. `app.js` 中的 API 地址是否正确
3. 是否关闭了域名校验（开发阶段）
4. 网络连接是否正常

### Q: 真机调试时无法访问 API？

**A:** 
1. 确保手机和电脑在同一局域网
2. 将 API 地址改为电脑的局域网 IP（不要用 localhost）
3. 查看电脑 IP：Windows 用 `ipconfig`，Mac/Linux 用 `ifconfig`

### Q: 如何发布正式版？

**A:** 
1. 申请微信小程序账号
2. 配置服务器域名（需要备案的 HTTPS 域名）
3. 在小程序后台配置合法域名
4. 修改 `app.js` 中的 API 地址为正式域名
5. 在开发者工具中点击"上传"
6. 在小程序后台提交审核

### Q: 生成菜单时提示"菜品不足"？

**A:** 
1. 确保后端已运行 `python init_db.py` 初始化数据
2. 检查数据库中是否有足够的菜品（至少 3 道菜 + 1 种汤）
3. 可以在"菜品管理"页面手动添加菜品
